# 生成工具与提供方适配

仅在用户要求直接生成图片、编辑参考图、批量候选或指定平台时读取。本 skill 不绑定厂商，也不自带账号、API Key或额度。

## 工具选择

1. 用户指定Seedream、内置生图工具或其他提供方时，先确认当前智能体确实拥有对应API、MCP、插件、函数或命令。
2. 指定工具可用则使用；不可用时不虚构调用结果，改用另一已授权工具，或输出完整可移植提示词。
3. 用户未指定时，选择当前环境中最适合静态生图或图像编辑的已授权工具。
4. 先编译提供方无关的主提示词，再映射画幅、参考图、负面提示和候选数量。

## 通用参数映射

- 画幅：优先使用原生16:9；只接受像素尺寸时选择该工具明确支持的最接近16:9横向尺寸，不拉伸成片。
- 参考图：只锁定空间几何、相机位置、主体比例、层级与光向；不复制界面、水印、文字和无关人物。
- 负面提示：支持negative prompt时单独传入；不支持时将最关键禁忌压缩到主提示词末尾。
- 多张候选：每张独立生成并保持同一参数锁定；不要默认在一张画布内生成九宫格。
- 图像编辑：若目标图片存在本地路径，先确认并传入；目标图只在对话中存在时使用环境支持的会话图片引用机制。
- 保存：把用户选中的最新版本复制到持久项目目录并使用可读名称；不要只依赖临时缓存。

## Seedream

- 将主体、唯一视角、尺度证据、空间层级、光色、材质和禁忌完整传入。
- 接口支持参考图或编辑时用参考图锁定构图；只支持文生图时用文字重建空间关系。
- 仅传当前接口文档或工具架构明确支持的字段；不要臆造模型名、尺寸枚举、种子、CFG或平台标志。
- 返回多个候选时逐张执行 `scale-audit.md`，不能只凭美观选择。

## 调用失败

- 工具不可用：输出可复制的正向提示词、负面约束和建议画幅。
- 工具返回错误：报告真实错误并尝试一次安全的已授权替代方案。
- 工具生成成功但违反硬约束：按审计修正最多两轮，不更换视角。
