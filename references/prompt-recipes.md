# 东方巨构提示词配方

只选择最接近用户请求的一种配方，再替换主题。不要把所有配方混入一张图。

## 云海天门

```text
一座从云海与山脊中生长出来的巨型东方门阙，单一主门统治画面，数公里长的石阶和层层台基沿中央轴线抬升。低机位从山门外仰望，前景两名极小旅人，中景古松与断桥作为尺度参照，远处主门轮廓被黎明逆光勾亮。玄黑木、风化青铜、灰白巨石，墨青与雾白为主，少量日金。庄严、沉静、真实材料厚度，大片云海留白。避免宝塔群、龙纹堆砌、红灯笼、随机汉字、霓虹、文字、水印。
```

## 湖心玄殿

```text
无风黑湖中央的巨大东方殿堂，低而宽的屋面与厚重台基形成唯一核心轮廓，一条极长石桥从画面前景直达主殿。近乎对称的正轴构图，倒影延长纵深，桥上少量微小灯火与人物提供尺度。冷月侧光刻出青铜、黑漆木和湿润石材，殿内仅有克制暖光。大片夜空与湖面留白，肃穆神秘。避免城市天际线、重复宝塔、艳丽霓虹、装饰拥挤、文字、水印。
```

## 沙海孤城

```text
无边沙海中的单体东方巨城，像被风蚀的巨大台阶山体，中心城门深黑，层叠城台沿主轴升向天空。远距离低机位，沙丘构成前景曲线，一支极小驼队和城门尺度形成强烈比较。夯土、砂岩、氧化铜，沙褐占主调，阴影呈墨蓝，夕阳只留少量赤金。风沙遮去次要细节，让整体轮廓清晰而孤绝。避免阿拉伯宫殿刻板符号、欧式城堡、宝塔复制、饱和红色、文字、水印。
```

## 东方未来天轮

```text
未来东方都城的核心是一座横跨山谷的巨型环形天轮，环内悬置一座低而宽的中央殿核，桥梁、轨道与城市台地沿礼仪中轴逐层汇聚。三分之四高远视角，山水与城市共同构图，飞行器极小且稀疏，只作尺度锚点。深青金属、玄黑陶瓷、雾白石材，能量光为低饱和玉色，晨雾与日光解释巨大体量。科技感来自结构与材料，不靠霓虹招牌。避免赛博朋克街景、密集广告、随机汉字、欧式飞船、文字、水印。
```

## 地下玄宫

```text
深埋山腹的东方地下玄宫，一个高耸如峡谷的矩形门洞成为唯一视觉中心，巨型柱列和悬空石桥层层通向门内。视点位于昏暗前殿，以门洞形成框中框；桥上几名微小人物、壁面瀑布和灯火标示尺度。顶部天井落下一束冷白光，深处透出微弱暖金，黑石、青铜与潮湿岩壁具有真实重量和年代。大面积暗部留白，肃静而非恐怖。避免骷髅、游戏 HUD、符号贴图、杂乱火把、文字、水印。
```

## 普通主题的转译示例

用户说：“一座下雨的图书馆。”

转译方向：保留图书馆与雨，把核心体量设为“峡谷般的中央书阁”，用长阶、门洞、层叠藏书台建立礼序；人物和书车只作尺度参照；雨幕与天井构成留白和主光。不要擅自增加神明、战争或复杂剧情。

用户说：“海边的未来空间站。”

转译方向：保留海边与空间站，把核心体量设为“环海天轮与中央殿核”，让发射轨道沿中轴伸向海面；使用深青金属、石白和少量玉色能量光；科技结构明确，但避免霓虹广告街。
