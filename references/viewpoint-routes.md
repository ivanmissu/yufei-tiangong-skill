# 东方巨构视角路由

每张静态图只选一个命名视角。先看相机所在位置，再看主导几何，最后看人物动作；命中后停止，不叠加其他视角。

## 路由表

| 用户意图或参考图空间关系 | 唯一视角 | 必须出现 | 禁止混入 |
|---|---|---|---|
| 身在殿内，经圆门、拱门或不规则巨洞看天外 | **殿内望天·巨型门洞框景** | 室内暗框、占画面一半以上的亮洞、洞外单侧锚点 | 巨柱矩形开境、巨月同心圆 |
| 从巨殿深处平视一整面矩形云海开口 | **云门内观·巨柱开境** | 上沿藻井、左右裁切巨柱、65–80%宽的亮开口 | 圆门、柱林仰拍、外部露台 |
| 人在柱林中向上看，被建筑高度吞没 | **柱林仰穹·极低机位** | 相机贴地、4–6根巨柱冲出上沿、中央天空 | 完整立柱陈列、平视门洞 |
| 刚抵达下一重门，从侧下方仰望巨阙 | **阙下侧望·门中重门** | 一侧厚台基、2–4根远柱围成高门、门后留空 | 正面对称柱林、横向长廊 |
| 沿宫殿外缘看悬檐、深渊和主云瀑 | **殿沿云瀑·悬挑侧景** | 一侧殿角、斜向巨檐、一道垂直云瀑、远端悬殿 | 多瀑布、宽广场、正面巨门 |
| 沿无尽弧形廊道行进 | **弧廊巡天·单点消失** | 单一弧线、连续柱列缩小、唯一消失点 | 第二廊桥、S形双曲线、中心宫殿 |
| 从巨构内部缝隙俯瞰上下夹住的云中山水 | **云阙峡谷·上下夹景** | 重型上下/侧框、中央竖向亮峡、最多一个浮岛或云瀑 | 多悬宫、多浮岛、普通开阔全景 |
| 以巨大圆框收纳月亮、松枝和孤峰 | **月洞借景·巨月山水** | 80–95%高圆框、错心巨月、横松、竖峰、角落人物 | 柱列、家具、科幻传送门 |
| 从松崖或窄台隔云遥望彼岸巨宫 | **松崖候宫·隔云对望** | 单侧古松、薄窄平台、大片云海、远而仍巨的横向主殿 | 中央松树、连岸桥、宫殿群 |
| 从较低较远露台向上看悬空宫殿外立面 | **檐下仰观·悬殿外立面** | 下沿薄露台、中央云渊、侧上方悬殿、裁切檐底 | 大前景地面、室内门框、普通走廊 |

## 冲突裁决

1. **机位优先**：室内选室内框景；外部下层露台选檐下仰观；贴地向上选柱林仰穹。
2. **几何其次**：超大圆框选月洞；单弧线选弧廊；纵向亮缝选云阙峡谷；斜檐加垂直云瀑选殿沿云瀑。
3. **动作最后**：隔云等待选松崖候宫；抵达下一重门选阙下侧望。
4. 参考图同时含多个元素时，只锁定其相机位置、主导几何、主体占比、空间层级与光向，不复制具体造型。
5. 仍有歧义时，选最能保留用户主要叙事的一个视角，并在提示词开头写 `Selected viewpoint: <唯一视角>`。

## 通用透视变体

- 横向城墙、巨门和长城阙默认采用斜切透视：近端切出画框，墙顶、墙基和结构线向远方汇聚。
- 只有用户明确要求庄严正视、绝对对称或图腾式构图时，才采用正面中轴。
- “远距离”不等于“高机位”；需要压迫感时保持人眼高度或较低机位。
