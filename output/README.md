# 九天之门 · 东方天宫巨构 2K 成片

使用 `yufei-tiangong-skill` 编译并生成的完整交付：从参数锁定、三轮尺度审计，到静态 2K 母版与锁镜图生视频。

## 参数锁定

| 字段 | 取值 |
|---|---|
| 工作模式 | 创建 → 直接生图 → 图生视频 |
| 画幅 | 16:9（用户指定），输出 2560×1440 |
| 唯一核心巨构 | 朱红天门（双檐、铜钉大门），单一统治层级 |
| 唯一视角 | 阙下侧望·门中重门（超广角低机位仰视变体） |
| 主导几何 | 中央单点透视 — 玉阶向天门收束 |
| 相机 | 贴地约 40cm、14mm 超广角、上仰 15° |
| 人物 | 1 名白衣旅人，背影 40°，0.9% 画面高（小于门钉） |
| 前景门槛 | 玉阶下沿 8–11%（硬上限 16%） |
| 光色 | 单右侧低位晨光；左冷右暖、近暖远冷 |
| 主奇观事件 | 云海横向翻涌 + 阶梯边缘向下云溢（仅一个） |

按 `references/scale-audit.md` 的修正顺序执行：先缩人物与前景，再放大远方巨构，最后统一主光。

## 视频编译

严格按 `references/video-motion.md` 编译，唯一运镜为**完全锁镜 0%**。

选择理由：本机位前景为约 10% 高石板台，任何前推或仰摇都会把台基放大成广场并引起巨门尺度漂移，属该文件明列的视频硬失败项，因此全部运动交给云海与光。

- 建筑像素锁死：天门/巨柱/阶梯/前景台帧差 max 4/255（仅颗粒）；位移遮罩按最大位移量外扩 64px 防止渗色
- 云海分层流动：远云慢、近云快；横向剪切 + 纵向涌浪 + 小尺度分形翻卷；阶梯脚下云溢流恒为向下
- 单一主光：右侧光束呼吸 ≤2.2%，首帧与源图曝光一致（帧差 1.86）

## 关于 2K

本环境的生图能力原生输出 1376×768，2K 由 LANCZOS + 双半径反锐化 + 轻颗粒提升而来（不虚构细节，云海无分层带）。

若需要原生 2K 像素，可用 Seedream 或任意 2K 文生图工具按 `output/tiangong-i2v-prompt.md` 中的场景段落重出一版，再套用同一锁镜提示词，运动方案可原样复用。
